## Main findings reported (keep the text consistent with them)

- epsilon-discarding (0.1.0) loses the Pareto set: 100% in the cycle
  configuration, 1.5% in the chain; not in the ties configuration (certificates
  appear in an order that avoids the cycle).
- Proposed procedure: zero false statements in Study 1 (6 configurations x 200),
  Study 2 and 2 x 20 repeated application runs.
- H2 only partly supported: repeated t erred in 3.5% (CI 1.4-7.1) of one
  configuration, below alpha; no correction never erred.
- H3 in direction only: open-pair allocation saves 18-44%, not increasing with K.
- Theorem 2 horizon with Hoeffding is in the millions (Table S1); betting needs thousands.
- Inventory truth is exact (Markov chain, `policy_exact()`); Monte Carlo truth
  would wrongly make (40,100) Pareto-optimal.
- Cover phase never finished within 1e5 evaluations in either application.

## Reproduce

Run from the package root, in this order (each script reads `PI_R` for the
number of replications; results are exact with 4 cores):

```sh
Rscript paper/code/00_install.R           # package into paper/.lib/current
Rscript paper/code/01_validity.R          # Study 1
Rscript paper/code/01b_validity_ties.R    # Study 1: ties and boundary
Rscript paper/code/02_efficiency.R        # Study 2
Rscript paper/code/03_applications.R      # applications (single runs cached, 20 repeats)
Rscript paper/code/04_planning.R          # Table S1 horizons
Rscript paper/code/fig1_failure.R; Rscript paper/code/fig_studies.R
Rscript paper/code/fig_apps.R;     Rscript paper/code/supp_tables.R
cd paper/manuscript && latexmk -pdf supplement.tex && latexmk -pdf main.tex && latexmk -pdf supplement.tex
```

Runtimes on a shared 4-core machine: Study 1 about 2 h, Study 2 about 1.5 h,
application repeats about 3 h. `results/cache/` (gitignored) holds the cached
single-run states and the inventory truth; it is regenerated by `03_applications.R`.
